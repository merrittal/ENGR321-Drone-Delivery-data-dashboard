# Drone Delivery Data Dashboard

A dashboard system that enables an autonomous drone to pick up and deliver a package from a sender to a designated destination. The system supports the complete delivery workflow from package request through navigation, delivery monitoring, and proof of delivery.

## Overview

The Drone Delivery Data Dashboard is designed to coordinate and visualize the lifecycle of an autonomous package delivery. It provides real-time visibility into drone operations, enabling users to request deliveries, track drone navigation, monitor delivery status, and confirm successful drop-off.

## Features

- **Package Request** — Senders can submit a delivery request specifying pickup location, destination, and package details.
- **Navigation** — The drone calculates and follows a route from the sender's location to the designated destination.
- **Delivery Monitoring** — Real-time tracking of the drone's status, location, and progress throughout the delivery.
- **Proof of Delivery** — Confirmation code generated once the package is delivered.

## Delivery Workflow

1. **Request** — A sender submits a package delivery request through the dashboard.
2. **Assignment** — An available drone is assigned to the request.
3. **Pickup** — The drone navigates to the original location and picks up the package.
4. **Navigation** — The drone follows the calculated route to the destination.
5. **Monitoring** — The dashboard displays live status updates (in transit, delayed, arrived, etc.).
6. **Delivery & Proof of Delivery** — The drone completes the drop-off and the dashboard logs proof of delivery.
