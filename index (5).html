The delivery workflow

01
Package Request
Fill out the Request Delivery tab with the recipient's name, drop zone, package weight, and any drop-off notes.
02
Navigation
On submit, the drone is assigned and plots a route — you're taken straight to Track Package to watch it fly.
03
Delivery Monitoring
The Track Package tab shows live position, altitude, speed, and ETA for the length of the flight.
04
Proof of Delivery
Mark the package received to log a proof-of-delivery code, or flag an error to send the drone back to origin.

Frequently asked

What does "Error — return to origin" do?
It sends the drone back the way it came instead of completing the drop-off. Use it if the package can't be delivered as planned. The attempt is logged as returned.
What is the proof-of-delivery code?
A unique code generated the moment a package is marked received, confirming the drop-off. It's saved with that delivery's entry in Logs.
Where do I see past deliveries?
The Logs tab lists every completed route, delivered or returned, with its weight class, status, and timestamp.
